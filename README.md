- 🎯 **Format A: PFP Frame / Overlay**: Circular & Square high-res avatar overlays with cyber HUD frames, decals, and verified residency tags.

- 💾 **1-Click 2K High-Res Download**: Instant client-side HTML5 Canvas rendering (no server latency).

- 🚀 **1-Click Share to X**: Opens Twitter/X with pre-filled caption, `#FrameInGoa`, `@247pmstudio`, and live generator link.

## 🚀 Getting Started

### 1. Run Locally
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```

### 3. Deploy in 1-Click (Vercel / Netlify)
You can deploy this repository to **Vercel** or **Netlify** with zero configuration:
- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`
